# NORYN AI
مشروع مساعد ذكي يُبنى تدريجياً باستخدام Python وFlask وHTML وCSS وJavaScript.

## الملفات
- `app.py`: خادم Flask ومسارات الموقع وواجهة API.
- `requirements.txt`: مكتبات Python المطلوبة.
- `templates/index.html`: صفحة الموقع.
- `static/style.css`: تصميم الواجهة.
- `static/app.js`: إرسال الرسائل وعرض الردود.
- `.gitignore`: استثناء الملفات السرية والمؤقتة.

## التشغيل المحلي
1. ثبّت Python.
2. نفّذ `pip install -r requirements.txt`
3. شغّل `python app.py`
4. افتح `http://127.0.0.1:5000`

## تنبيه
رد المحادثة تجريبي حالياً ولم يُربط نموذج ذكاء اصطناعي حقيقي بعد. لا تضع مفاتيح API في ملفات الواجهة أو مستودع GitHub.
